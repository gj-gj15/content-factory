# 双通道内容工厂 · 架构

## 星型结构（hub-and-spoke）

```
                        用户
                         │
                         ▼
                ┌─────────────────┐
                │   总智能体 总控   │   ← 唯一枢纽
                │  (全局总览/路由) │
                └────────┬────────┘
           ┌─────────────┴─────────────┐
           │ 派发 / 回执（唯一信息通道） │
           ▼                            ▼
   ┌──────────────────┐      ┌──────────────────┐
   │   视频通道子智能体 │      │   文案通道子智能体 │
   │  (成片产线 01-08) │      │  (成文产线 01-08) │
   └────────┬─────────┘      └────────┬─────────┘
            │                          │
            ▼                          ▼
     shared backbone (stages 01-08 + pipeline_state.py)

   ⚠ 视频通道 ──X── 文案通道   （禁止直连）
```

## 数据流
1. 用户目标 → 总控。
2. 总控 `init` 状态机，按 `routing.md` 决策通道，派发 slug。
3. 子智能体按 backbone 阶段卡逐段执行，每阶段 `pipeline_state.py stage ...` 落盘。
4. 子智能体向总控回执（不直连另一条通道）。
5. 总控 `show` 聚合，给用户全局总览。

## 铁律
- 子智能体之间禁止互相直连，一切经总控中转。
- 总控不亲手执行步骤，只调度 + 汇报。
- 阻塞如实标注（如视频通道缺 API），不假装跑通。
