# 去 AI 味（anti-ai-tone）

> 双通道共用。生成**源头**（core-copy 母体）即生效，质检（06）复核，不是事后救火。
> 设计目标：写给「人」看的，不是写给「模型评测」看的。桂哥标准——能直接发给客户、说人话、有观点、反冗长。

## 一句话定义
AI 味 = 信息密度低 + 没有立场 + 套话垫话 + 表演式排版。去掉这三样，就是人话。

---

## 一、生成期坏特征（写的时候逐条避）

| 类型 | 坏样子 | 好样子 |
|---|---|---|
| 套话垫话 | "在当今这个信息爆炸的时代…"、"随着…不断发展"、"众所周知" | 第一句直接入题，不铺垫 |
| 否定式排比 | "不是…不是…而是…"（全文 ≤1 次） | 直接说是什么 |
| 平衡腔/复读总结 | "总而言之/综上所述/可以说" | 删。结尾给行动或悬念 |
| 空泛拔高 | "标志着/见证了/具有重要意义" | 换具体事实或动作 |
| -ing 装深度 | "彰显着/呼应着/体现着" | 删整短语 |
| 模糊归因 | "业内人士认为/专家表示"（无具名） | 给具名来源或删 |
| 宣传腔黑话 | 臻选/卓越/赋能/致力于打造/抓手/闭环/生态/赋能/落地 | 换人话动词 |
| 机械序号 | 全文"首先/其次/最后""第一/第二" | 用故事或逻辑推进，不靠序号串 |
| 表演排版 | 每段都——破折号、emoji 轰炸、全员加粗 | 破折号 ≤2 篇、emoji 克制、只加粗真重点 |
| 均匀句长 | 连续 5+ 句一样长 | 长短交错 |
| 讨好收尾 | "希望对你有帮助"、"如有疑问欢迎…" | 不收尾式讨好，留钩子 |

---

## 二、去味操作（怎么写才像人）

1. **具体替代抽象**：给名字、数字、地点、时间、场景。不说"很多人"，说"我楼下菜市场三个摊主"。
2. **有观点敢下判断**：敢说"这个方案不行""我赌它活不过半年"。AI 味的根是没立场，给立场。
3. **短句优先**：一句一个意思，能断就断。长句只在需要强调时用。
4. **砍一切垫话**："其实""说实话""不得不说""值得注意的是"——删掉句子照样成立就删。
5. **一意一段**：一个段落只服务一个意思，别把三个观点揉一段。
6. **禁 B 端黑话**：赋能/抓手/闭环/生态/维度/赛道/落地/助力/打造/夯实。命中即换。
7. **不总结式收尾**：结尾要么给行动，要么留悬念，要么抛一个问题。别"综上所述"。
8. **给真实细节**：具体对话、具体金额、具体时间点的冲突。细节是反 AI 味的最强武器。

## 三、人味注入（删完坏特征后必验，至少注 3 项）

| 项 | 怎么做到 |
|---|---|
| 有观点 | 明确站边，不左右逢源 |
| 承认复杂 | 说"这事没那么简单"，不假装全知 |
| 节奏变化 | 长短句、轻重交替，不匀速 |
| 第一人称 | 适度用"我/我们"，别通篇第三人称客观腔 |
| 具体感受 | 写"看着心惊""越想越不对"，不只有事实 |
| 留毛边 | 允许一点不圆满、不圆滑的真实感 |

## 四、生成期铁律（core-copy 套用，04 执行第 4 步）

- 开场禁问候铺垫，第一句入题。
- 数字密度 ≤3 处/篇，比喻 ≤3 处/篇。
- verdict（核心观点）必须含一个**可转发的意象**（一句话能复述的画面/结论）。
- 共情不嘲讽，立场清晰不站队极端。
- 去 AI 味**不许牺牲事实准确**：为做人味编细节 = 违规，宁可留白。
