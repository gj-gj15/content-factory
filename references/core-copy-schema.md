# core-copy 字段定义（双用母体）

`outputs/<topic>/core-copy.md` 是**形态无关**的内容本体，视频通道与文案通道共用。它不含分镜、不含排版——只承载"这条内容到底在讲什么、怎么讲才有人味"。

## 必填块（每块用 `## 块名` 二级标题）

- `核心观点`：一句话说清这条内容到底在讲什么。禁正确废话、禁总结腔。
- `目标受众`：谁看。写**人/场景/处境**（"老家有块宅基地闲置的农房主"），不是人口统计标签。
- `钩子`：开场第一句。人/场景/处境先行，禁"大家好""今天聊聊"。
- `逻辑链`：3-5 个论点，每个结构 = `观点 + 证据（数据/故事）+ 一句人话收束`。
- `关键数据`：≤3 组，标注来源与可信度；多余转可视化或留作视频图表。
- `金句`：可转发的具体意象句（verdict 级），1-3 句。这是双形态都抢着用的资产。
- `行动号召`：看完要做什么（加微 / 留言 / 看主页 / 转发 / 填表）。
- `情绪基调`：共情不嘲讽；红线话题（心理危机等）单独标注、发布前单独过确认门。

## 可选块
- `禁忌`：不能说的（品牌/合规/平台红线）。
- `参考素材`：采集到的原始素材指针。
- `平台适配备注`：哪些点视频更强（演示/情绪）、哪些图文更强（清单/对比）。

## 双向互转时的回填规则
- 已有视频脚本 → 反推：从 `script-final.md` 抽 核心观点/钩子/逻辑链/金句/行动号召 → 填回 core-copy。
- 已有图文推文 → 反推：从 `wechat-draft.md` / `xhs-note.md` 抽同上字段 → 填回 core-copy。
- 反推后另一通道只读 core-copy 加工，不互读对方形态化产物（符合"子智能体互不直连"铁律）。
