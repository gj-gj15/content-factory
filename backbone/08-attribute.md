# 08 数据（attribute）

> 取材自 `content-distribution-team/1.0.1/skills/multi-platform-distribution/references/platform-data-analytics.md`。
> ⚠️ 该团无数据回流代码，本环境做法：**发布后人工从后台抄数回填**。下面给可直接套用的口径与公式。

## 1. 统一指标与权重
| 指标 | 权重 |
|------|------|
| 点赞 Likes | 1× |
| 评论 Comments | 3× |
| 分享 Shares | 5× |
| 收藏 Saves | 2× |
| 关注转化 Follows | 10× |

## 2. 核心公式
- 标准互动率 = (赞+评+享+藏) / 曝光 ×100%
- **加权互动率** = (赞×1+评×3+享×5+藏×2) / 曝光 ×100%
- **CQS** = 互动率得分40% + 完播率得分30% + 粉丝转化得分20% + 分享率得分10%
  每项得分 = min(100, (实际值/平台基准值)×60)，总分 0-100

## 3. 平台基准（互动率，10万粉级参考）
抖音 5-10% / 小红书 4-8% / B站 3-6% / TikTok 6-12% / 视频号 4-8%
完播率基准（抖音60s）：合格>25% / 良好>35% / 优秀>50%

## 4. 归一化（跨平台对比用）
- 基准比值法：归一化 = 实际值 / 平台基准值（>1 即超标）
- Z-Score：Z=(X-μ)/σ，Z>1.5 爆款级，<-1.5 需诊断

## 5. A/B 测试模板
单变量控制（只改标题/封面/时长之一），样本 ≥10 对，差异>20% 且持续 3 次才确认。

## 产物（按 `references/delivery-spec.md`）
`outputs/<topic>/汇总/数据回填.md`：各平台数据回填表（曝光/互动/完播/涨粉）+ CQS + 归一化对比 + 下一轮优化点。交付附**绝对路径**。
