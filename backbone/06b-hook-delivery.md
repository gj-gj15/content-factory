# 06b 钩子交付（hook-delivery，v2.1 新增 · 方向 B）

> 定稿后单独触发，生产文案里**承诺给读者的实体"钩子"交付物**。
> 完整版直接生成（调用搜索/采集真实信息）；缺料标 ⚠️ 让用户补，不交空壳。

## 触发
总控在 06 定稿后派发本步。文案通道与视频通道均适用（视频脚本里"评论区领模板"等同样算钩子）。

## 执行
1. **提取承诺型钩子**：扫定稿成稿，列出所有"承诺交读者的实体资料"——
   如"后台领XX模板""附赠XX清单""我整理了XX事件始末""文末送XX方案""XX技能文档"。
   每条记：承诺内容 / 文中位置 / 读者为何要。
2. **逐个生产完整版实体交付物**（落盘 `outputs/<topic>/hooks/<hook-slug>.md` 或对应格式）：
   - 事件整理 → 结构化梳理（时间线 / 各方观点 / 结论 / 信源）
   - 方案交付 → 可执行方案或模板文档
   - 技能文档 → 技能说明或操作手册
   - 清单/模板 → 可直接用的文件
   - 需真实信息 → 调 WebSearch / 采集；搜不到标 ⚠️ 附"待你补：XXX"
3. **不漏承诺**：成稿里写了但工厂做不出的，也要在清单里列明状态（已交付 / 待补），不许默默跳过。

## 交付（落盘文件 + 对话呈现）
- `outputs/<topic>/汇总/钩子资料/` 目录：每个钩子一份完整交付物，**中文文件名**（见 `references/delivery-spec.md`）。
- `outputs/<topic>/汇总/钩子清单.md`：钩子清单（承诺内容 / **绝对路径** / 状态）+ 摘要。
- 对话中呈现清单与每个交付物摘要，**路径一律用绝对路径**，让用户能直接去拿。

## 与 07 关系
钩子资料可作为 07 分发的"资料包"附件（如公众号推文配下载资料 / 视频简介放文档链接）。

## 状态机
`pipeline_state.py stage --topic <slug> --stage produce --status done --note "钩子交付：N 份已产出，M 份待补"`
