# 02 策划（plan）

> 取材自 `viral-toolkit`（使用顺序）+ `opc-team/1.0.0/skills/opc-conversion-loop`（conversion-patterns）。
> 本地零依赖，纯方法。

## 1. 承接 discover 的产出
读取 `discover.md` 的「主基因 + 传播锚点」，本阶段把它落成一个可执行的**内容形态方案**。

## 2. 选转化路径（opc 四选一）
| 路径 | 适用 | 末端承接 |
|------|------|---------|
| 内容 → 私信 → 咨询 → 成交 | 高客单/定制服务 | 私信话术 |
| 内容 → 表单 → 诊断 → 成交 | 需留资的咨询 | 落地页/表单 |
| 内容 → 低价产品 → 升级服务 | 知识付费/标品引流 | 低价品链接 |
| 搜索流量 → 落地页 → 预约 → 成交 | 强搜索意图 | 预约入口 |

> 注意：本层只**规划**承接方式，不写 CRM、不搞线索系统（见 mapping.md 断点④）。承接落点先记一句，真实跑时再填。

## 3. 内容形态决策
- 视频优先 or 图文优先？看选题锚点（对比图→图文；场景叙事→视频）
- 多形态联动（核弹级 ≥35 分才做）：24h 内快评/梗图 → 24-72h 主力成片 → 72h 后复盘。

## 4. 确认门 plan-confirm
`python pipeline_state.py gate --topic <topic> --gate plan-confirm --value passed`
未过门不开工。门里要回答：形态定了？锚点能截图传播？转化路径选了？

## 产物
`outputs/<topic>/plan.md`：内容形态 + 转化路径选择 + 多形态排期（若有）+ 确认门状态。
