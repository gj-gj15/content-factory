# 01 选题（discover）

> 取材自 `ai-media-ops-team/1.2.1/skills/viral-toolkit`（prefilter-12 / scoring-8dim / title-formulas）。
> 本地零依赖，纯方法，可直接用。

## 流程（顺序不可跳）
```
选题入口(两条路) → [A 工厂出榜: 找热点引导式0.1-0.3 → 热榜候选 → 用户选榜] / [B 用户直供: 用户拍选题直接进评估] → 12心法亮灯 → 4基因匹配 → 8维打分 → 标题≥4套公式 → 评估确认门(用户确认才init/派发)
```

## 0. 选题入口（两条路，评估对两条路都强制）

触发：用户说"找热点 / 今天发什么 / 给个选题"等。**这一步是与用户的对话本身，逐步问答，不许一口气问完，不许跳问。**

**B 路·用户直供选题**：用户直接给出选题（"我要做 X""这条帮我跑""评估一下这个题"）→ **跳过 0.1-0.2 采集，直接进第 1 节 12 心法评估**。直供选题一样要过亮灯+打分+标题+确认门，没有"用户给的题免检"这回事。

### 0.1 范围问答（顺序固定）

1. **平台多选**：先读默认值 `outputs/factory-config.json`。
   - **有默认值** → 开场一句话："沿用默认范围：平台=微博+抖音，行业=科技。直接按这个搜？回复'改'调整范围。" 用户说直接搜 → 跳到 0.2。
   - **无默认值** → 出多选单，**停下等用户选完**才进下一问：

   | 选项 | 平台 |
   |---|---|
   | 1 | 微博热搜 |
   | 2 | 抖音热点 |
   | 3 | 百度热搜 |
   | 4 | 知乎热榜 |
   | 5 | 今日头条 |
   | 6 | B站热榜 |
   | 7 | 小红书热点 |
   | 8 | 快手热榜 |
   | 9 | 全网聚合（兜底） |

   用户可回 "1+3+4" 组合或 "9 全网"。

2. **行业/关键词**：问"聚焦哪个行业或关键词？（回复'不限'=全站）"可多词，如"科技 AI"。

3. **平台记默认**：问"把这套平台组合记为默认值，以后每次都按它搜？（是/否）"是 → 写入 config。

4. **行业记默认**：问"把这个行业/关键词也记为默认值？（是/否）"是 → 写入 config。

### 0.2 采集出榜

- 按确认的范围逐平台搜索当日热榜（查询词带当天日期），过滤出与行业/关键词相关的条目。
- 出榜格式，4-8 条：

  `# | 话题 | 来源平台 | 热度佐证 | 时效窗口`，末尾附你的推荐 + 一句理由。

- **停在这里等用户选题。** 用户没选之前：禁止 init 状态机、禁止派发子智能体、禁止进入心法评估。选题后才走下方 1-4。

### 0.3 默认值文件

路径：`outputs/factory-config.json`（与各选题目录平级）。

```json
{
  "platforms": ["weibo", "douyin"],
  "industry": "科技",
  "keywords": [],
  "updatedAt": "2026-10-14T19:50:00+08:00"
}
```

平台代号：weibo / douyin / baidu / zhihu / toutiao / bilibili / xiaohongshu / kuaishou / all。
写默认值 = 覆盖整个文件；改范围 = 按本次回答覆盖后再次向用户口头确认一遍。

## 1. 12 心法预筛（逐条亮灯）
🔴 红线命中 1 条直接淘汰；🟡 黄线命中 ≥2 条返工。

| # | 心法 | 级别 | 判据 |
|---|------|------|------|
| ① | 用户思维优先 | 🔴 | 一句话答出"谁转、转给谁、TA 得到什么"；受众写"年轻人/大众"=淘汰 |
| ② | 热度足够 | 🔴 | ≥2 平台同时上榜且曲线未拐头；日抛热点须 24h 内能发 |
| ③ | 传播点明确 | 🔴 | 有"截图即传播"的瞬间（结果页/对比图/梗图），能描述出那个画面 |
| ④ | 可视可交互 | 🔴 | 道理能变画面/动作/数字，而非纯文字 |
| ⑤ | 叙事张力 | 🔴 | 有冲突/反转/悬念；不靠猎奇造谣 |
| ⑥ | 化繁为简 | 🔴 | 一个选题只服务一个核心观点；6 字内总结不出就回去砍 |
| ⑦ | 体验一致 | 🔴 | 封面/首屏/结尾视觉与信息密度一致 |
| ⑧ | 门槛低 | 🔴 | 主流程 3 步内、首屏 5 秒懂 |
| ⑨ | 声音加成 | 🟡 | BGM/音效是加分不是必需；静音不尴尬 |
| ⑩ | 立场安全 | 🔴 | 地缘/政治/性别/阶层只呈现事实不站队 |
| ⑪ | 信源可信 | 🔴 | 关键事实 ≥3 权威信源可追溯；"网传/据说"=淘汰 |
| ⑫ | 合规可上线 | 🔴 | 广告法绝对化词/肖像权/诱导分享/平台规则逐项过 |

**亮灯输出格式**：`①✅ ②✅ ③⚠️(锚点弱→建议改XX) … 结论：进入打分/返工第X条/淘汰(红线③)`

## 2. 爆款四基因（匹配 2-3 条当主引擎）
情绪钩子 / 信息差 / 身份标签 / 行动触发

## 3. 8 维打分卡
每维 1-5 分。**总分 ≥30 合格，≥35 核弹级，<30 淘汰或回炉。** 必须给具体分值和一句依据。

| 维度 | 打分问题 | 5 分标准 |
|------|---------|---------|
| 情绪 | 唤醒什么情绪？ | 强情绪+高唤醒 |
| 传播 | 用户为什么转？ | 转发能完成自我表达 |
| 独家 | 我们有什么别人没有？ | 独家数据/亲历/角度 |
| 身份 | 转发者向谁宣告？ | 精准圈层标签，转发即表态 |
| 时效 | 窗口期剩多久？ | 72h+ 或常青 |
| **锚点** | 截图传播的画面？ | 一眼可描述、可炫耀/吐槽（强制项） |
| 可视化 | 核心信息能否一图讲清？ | 一张主视觉能独立传播 |
| 门槛 | 理解+互动成本？ | 3 步内/5 秒懂 |

输出：`选题：{{冲突点+受众+利益}} ①情绪4(…)…⑧门槛5(…) 总分：32 ✅合格 ｜ 主基因：信息差+身份标签 ｜ 传播锚点：XX对比图`

## 4. 标题公式（每选题起 5 条，≥4 套不同公式）
数字冲击 / 反差颠覆 / 悬念缺口 / 身份点名 / 成本揭秘 / 警示避坑 / 亲历叙事 / 对比测评 / 结果前置 / 提问互动 / 借势热点 / 清单交付。
铁律：不堆 ≥2 强情绪词；数字用奇数+具体值；禁"最/第一/绝对"；禁 B 端黑话（赋能/抓手/闭环）。
平台字数硬限：朋友圈≤22 / 小红书≤20 / 公众号≤28 / 视频号抖音≤22 / 海报≤14。

## 5. 评估确认门（不可跳过，init/派发的前置闸口）

评估不是内部动作，是给用户看的质检单。无论选题来自工厂出榜（A 路）还是用户直供（B 路），**必须先把下面这张表拿给用户，用户明确说「确认/开跑/就它」才允许 init 状态机、派发子智能体**：

```
选题评估单
① 12心法亮灯：①✅ ②✅ ③⚠️(锚点弱→建议改XX)… 结论：合格/返工第X条/淘汰(红线③)
② 8维打分：情绪4 传播3 独家5 身份4 时效3 锚点4 可视化3 门槛5 → 总分31 ✅合格
③ 标题≥4套（附公式名）
④ 我的建议：值得跑 / 改完再跑 / 建议换题（一句话理由）
```

裁决规则：
- **用户确认** → 进 init/派发（标准流程第 1 步）
- **用户打回**（"分低了/换个题/改改再跑"）→ 针对打回点修订选题或重出候选，重新走第 1-4 节评估，再上确认门
- **评估淘汰**（红线命中或总分 <30）→ 如实告知"这题不该做"并给依据；用户坚持要做 → 记录一句「用户坚持低分开工」，不强行阻拦
- 直供选题预估分 <30 时，主动给 1-2 个替代方向再上确认门，别让用户硬着头皮跑废题

### 5.1 深评升级（topic-evaluator 联动，不可跳过触发条件）

满足任一条件时，**总控自行派发 `topic-evaluator`（科技侠来了）做深度评估**（subagent 派发，与派发通道子智能体同一机制，不需要用户手动切换专家）：

| 触发条件 | 说明 |
|---|---|
| 用户明确要求深评 | 「帮我深评这个题」「好好评估一下再做」 |
| 8 维打分 30-34 边缘区 | 可过不过，让深评定夺 |
| 大投入选题 | 要出镜拍摄、系列化连载、商单合作 |
| 心法亮灯有黄线或争议项 | 立场安全/信源可信等灰区 |

派发时附上：选题陈述 + `account-positioning.json` 路径（有定位时）+ 工厂初步评估结果（亮灯+打分）。
深评报告回收后并入确认门：
- 深评 ≥30/40 → 放行
- 深评 <26/40 → 如实告知 + 替代方向；用户坚持 → 记录「用户坚持低分开工」
- 深评有方向建议 → 写进本文件产物 `outputs/<topic>/discover.md`，随生产全程带下去
- 派发失败或 topic-evaluator 未安装 → 降级只用工厂快筛，确认门注明「未经深评」

## 产物
`outputs/<topic>/discover.md`：预筛亮灯 + 打分卡 + ≥4 标题 + 选定传播锚点。
